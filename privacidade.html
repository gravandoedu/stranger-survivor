Política de Privacidade

Stranger Survivor Publisher · Última atualização: 31 de outubro de 2026.

Esta Política explica quais dados o Stranger Survivor Publisher usa, para que serve e como são armazenados. O app é operado por Stranger Survivor.

1. Dados que o app usa

  • Token de acesso do TikTok, recebido quando você autoriza o app pelo login oficial.
  • Informações básicas do perfil autorizado, necessárias para confirmar a conta que receberá o vídeo.
  • Vídeos, legendas e configurações de publicação escolhidos por você.

2. Para que os dados são usados

Os dados são usados apenas para autenticar a conta autorizada e enviar os vídeos escolhidos por você para o TikTok, com a legenda e a privacidade que você definir.

3. Onde ficam armazenados

Os tokens, vídeos e registros ficam no computador do responsável, em arquivos locais. O app não mantém um servidor na nuvem com esses dados.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos seus dados com terceiros para publicidade. Os vídeos e as legendas são transmitidos à API do TikTok porque isso é necessário para publicar o conteúdo na conta autorizada. O tratamento feito pelo TikTok segue a política de privacidade da própria plataforma.

Este site não usa cookies de rastreamento, analytics ou anúncios.

5. Retenção e exclusão

Os dados ficam guardados enquanto a autorização estiver ativa. Você pode revogar o acesso nas configurações do TikTok e pedir a exclusão dos dados locais pelo contato abaixo. A exclusão dos dados não apaga conteúdos que já tenham sido publicados no TikTok.

6. Segurança

O acesso aos arquivos é restrito ao computador do responsável. Nenhum método é 100% seguro, mas o app evita expor tokens em páginas públicas e não envia credenciais para terceiros.

7. Seus direitos

Você pode solicitar informações, correção ou exclusão dos seus dados pessoais, conforme a Lei Geral de Proteção de Dados (LGPD). Para isso, use o contato abaixo.

8. Crianças

O app não é destinado a menores de 13 anos e não coleta intencionalmente dados de crianças.

9. Alterações

Esta Política pode ser atualizada. A versão vigente é sempre a publicada nesta página, com a data de atualização no topo.

10. Contato

Para dúvidas ou solicitações: gravandoedu@users.noreply.github.com.
